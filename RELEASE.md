# чатбот_гарант_версия 1.2.2

Чат-бот ВКонтакте и консоль: диалог на GPT-4o Mini (ProxyAPI), новости ГАРАНТ ПРАЙМ и шаблоны договоров.

Дата: 20.10.2026.

## Что нового относительно 1.2.1

Шаблоны договоров из ГАРАНТ в Word.

- Фразы «шаблоны договоров», «шаблон N» и «шаблон» с частью названия. Кнопки нет, AI для этих фраз не вызывается.
- Список длиннее 10 пунктов листается командой «ещё». Один шаблон приходит файлом: в VK — документом, в консоли — путём к файлу.
- `GET /v2/topic/5703683/html` даёт каталог, `GET /v2/topic/{id}/download` — RTF. DOCX делает LibreOffice (`soffice`). Нет LibreOffice — остаётся RTF.
- Повторная выгрузка берёт уже скачанный файл, если `last_modified` не менялся. `ACCESS_BY_MONEY`, `ACCESS_BY_REQUEST` и `ACCESS_DENIED` пропускаются. 423 останавливает выгрузку.
- В режиме `browser` и без `GARANT_TOKEN` бот пишет, что шаблоны доступны только в режиме `api`.
- Выгрузка диалога VK запускается как `python -m exports.export_vk_history`.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
playwright install chromium
copy .env.example .env
python main.py --vk
```

В `.env` нужны `VK_TOKEN` и `PROXYAPI_KEY`. Для API-новостей, лимитов и шаблонов: `GARANT_TOKEN` и `GARANT_MODE=api`. Для `.docx` — LibreOffice (`LIBREOFFICE_PATH`, если `soffice` не в PATH). Для browser: `GARANT_LOGIN`, `GARANT_PASSWORD`, `GARANT_MODE=browser`. У токена VK должно быть право документы (`docs`).

## История предыдущих версий

### Версия 1.2.1

Остаток квоты API ГАРАНТ по фразам в чате (см. также [описание текущего релиза](#что-нового-относительно-121)).

- «лимиты» или «остаток запросов» — `GET /v2/limits`: сколько вызовов каждого семейства методов осталось в этом месяце.
- Кнопки в меню нет. В режиме `browser` и без `GARANT_TOKEN` бот отвечает, что лимиты доступны только в режиме `api`.
- Та же строка добавлена в справку и в каталог сфер.

### Версия 1.2

Паритет фильтров режима `browser` с `api` на `internet.garant.ru` (см. также [описание текущего релиза](#что-нового-относительно-121)).

- Лента: `GARANT_BROWSER_BASE_URL`, по умолчанию `https://internet.garant.ru`; вход через `account.garant.ru`.
- Территория и вид информации доступны только без выбора темы.
- Меню «за неделю» / «за месяц» — радио на сайте; свой период — даты `ДД.ММ.ГГГГ-ДД.ММ.ГГГГ` в полях «За период».
- «Главные новости» — период без узкой темы (на сайте нельзя OR нескольких сфер одним чекбоксом).
- Полные ссылки на документы; лента не ограничена 20 карточками первой страницы (пагинатор сайта).
- Справка с PDF-каталогом сфер вложением документа VK: повтор загрузки и кэш документа.
- Сбой входа (alreadyused, заглушка без «Войти») — просьба подождать, не пустая лента. Повтор того же запроса в кулдаун не логинится заново.
