# Известные ограничения — технические подробности

Подробности перенесены из README при сокращении основного описания. Даты и результаты прежних проверок приведены как исторические сведения; перенос документации не означает повторного испытания внешних сервисов.

- История диалога хранится в памяти процесса (`InMemoryDialogueHistory`) — без персистентности, теряется при перезапуске. Ограничена по количеству последних сообщений (не по токенам). Структура (`DialogueHistory`) уже позволяет добавить персистентную реализацию позже без изменений в остальном коде.
- Распознавание новостных запросов — сначала keyword-matching по основам слов (`IntentRouter.route`), затем при намёке на юридическую лексику один AI-классификатор в JSON. Это не полный NLP и не вызов AI на каждое сообщение. Кнопки VK-клавиатуры шлют обычный текст (в том числе «➡️ Показать ещё») — отдельного механизма callback-кнопок нет.
- Кэш страниц новостей (`InMemoryNewsResultsCache`) живёт в памяти процесса, как история диалога: после перезапуска «ещё» просит сначала сделать новый новостной запрос.
- `GarantPrimeParser`: логин, лента и apply фильтров на `internet.garant.ru` подтверждены 10–11.09.2026. После «Применить фильтры» ждём «Лента отфильтрована» / «Ничего не найдено», не класс `.resetFilter` на панели. Неделя/месяц — радио сайта; набор дат в «За период» для кнопок меню на срезе 10.09.2026 давал пустую ленту. Тема на сайте может называться иначе, чем в API («детективная» вместо «сыскная»). Территория/вид информации только без темы. `demo.garant.ru` в тот период не подтверждён (alreadyused). Кулдаун между входами — 60 с; alreadyused и заглушка без «Войти» в чат уходят как просьба подождать. Первая страница сайта — ~20 документов; дальше листается `ul.paginator` (верхняя граница `MAX_FEED_PAGES = 100`). Длинные карточки VK режет по лимиту сообщения (обрыв на полуслове).
- Точная дата отдельной новости в режиме `api` (`fetch_exact_dates=True`, доп. запрос `GET /v2/topic/$topic` на каждую новость) реализована, но выключена по умолчанию и не проверена end-to-end через `BotCore` (лимит — 300 запросов этим методом в календарный месяц).
- `authority`/`doc_type`/`keywords` (`NewsQuery`) — осознанно не поддерживаются ни одним режимом в этой итерации: у метода «Лента Прайм» нет для них параметра (см. докстроку `NewsQuery` в `core/models.py`); единственный подтверждённый механизм — язык запросов метода «Поиск» (`POST /v2/search`), не реализован и не подтверждён живым вызовом (см. сведения о проверках в [README](../README.md)). Если эти поля заданы — они логируются как игнорируемые, не имитируются.
- Произвольная тема в чате — MVP, не NLP: шаблоны «из сферы / по сфере / в сфере», «новости по X» и остаток текста после дат или «за N …». Нет совпадения с деревом сфер — пустой ответ без запроса к ленте, не широкий fallback по всем категориям.
- Вложение каталога сфер в VK требует права `docs` у токена сообщества и (для свежей печати) установленного Chromium Playwright. Без права или при сбое загрузки справка в чат всё равно уходит, но без PDF.
- Территория (`REGION_KEYWORDS` в `IntentRouter`) — небольшой курируемый список регионов (Москва/Санкт-Петербург/Татарстан), не полный справочник субъектов РФ.
- Режим `mcp` (`mcp.garant.ru`) — только архитектурная заготовка (`core/news/parser_mcp.py`, `GarantMcpParser`), реального MCP-клиента нет; `GARANT_MODE=mcp` даёт понятную ошибку конфигурации при старте, а не рабочий режим.
- Свой период задаётся датами в тексте (`ДД.ММ.ГГГГ-ДД.ММ.ГГГГ`); календарного виджета в VK нет (потребовался бы отдельный VK Mini App). Формат, примеры и ссылка на каталог сфер — в справке.
- Новый интерфейс (например, Telegram) — только архитектурная точка расширения (`interfaces/_future/`), сама реализация не входит в эту итерацию.
