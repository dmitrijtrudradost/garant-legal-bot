# VK AI-бот

Чат-бот ВКонтакте (и локальная консоль) с AI на базе GPT-4o Mini через ProxyAPI, плюс модуль новостей ГАРАНТ ПРАЙМ.

## Возможности

- Приветствует нового пользователя по имени
- Отвечает на сообщения с помощью GPT-4o Mini, с историей диалога (контекстные ответы)
- Распознаёт новостные запросы («что нового по охране», «изменения в законодательстве» и т.п., независимо от падежа/числа слов) и присылает подборку новостей ГАРАНТ ПРАЙМ по готовым пресетам (охрана / налоги и бухучёт / всё сразу), с учётом периода («за неделю» / «за месяц» / «за 3 месяца» — по умолчанию неделя)
- В VK-версии под каждым сообщением бота — постоянная клавиатура для новостей ГАРАНТ (по одной кнопке на строку, чтобы текст не обрезался на смартфоне): «🛡 Охрана — месяц», «📋 Главные новости — месяц», «📅 Свой период» (запрашивает даты текстом в формате ДД.ММ.ГГГГ-ДД.ММ.ГГГГ, с любым периодом и темой). Кнопка — это просто предзаполненный текст, обычный ввод продолжает работать точно так же
- **Важно про VK-клавиатуры**: они появляются только если в настройках сообщества включены «Возможности ботов» (Управление сообществом → Сообщения → Возможности ботов). Без этой настройки VK отклоняет отправку клавиатуры — бот автоматически подстраховывается и присылает тот же текст без кнопок, а не молчит
- Один и тот же функционал доступен и через VK, и через локальную консоль — оба интерфейса работают поверх общего ядра

## Установка

Полная пошаговая инструкция (локально и на удалённом сервере, включая запуск как systemd-сервиса) — в [INSTALL.md](INSTALL.md). Коротко:

```bash
git clone <репозиторий>
cd задание_9_vkbot_парсер

# Создание виртуального окружения
python -m venv .venv

# Активация
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Windows (CMD):
.venv\Scripts\activate.bat

# Установка зависимостей
pip install -r requirements.txt

# Браузер для модуля новостей ГАРАНТ ПРАЙМ (см. раздел "Модуль новостей" ниже)
playwright install chromium
```

## Настройка

1. Создайте сообщество ВКонтакте: https://vk.com/editapp?act=create
2. Включите в настройках сообщества обработчик сообщений (LongPoll API)
3. Получите токен сообщества
4. Зарегистрируйтесь на https://proxyapi.ru и получите API-ключ
5. (Опционально, для новостей ГАРАНТ) — логин и пароль для входа на demo.garant.ru

Создайте файл `.env` в корне проекта:

```
VK_TOKEN=ваш_токен_сообщества
PROXYAPI_KEY=ваш_ключ_proxyapi

# Для модуля новостей ГАРАНТ ПРАЙМ (см. ниже)
GARANT_LOGIN=
GARANT_PASSWORD=
```

Без `GARANT_LOGIN`/`GARANT_PASSWORD` бот продолжает работать как обычно — на новостной запрос он ответит «изменений не найдено» (источник недоступен без учётных данных), при этом весь остальной функционал (диалог, приветствие) не затрагивается.

## Запуск

```bash
python main.py --vk          # VK-бот (по умолчанию — так же работает и просто `python main.py`)
python main.py --console     # локальный чат в терминале, тот же функционал без VK
```

Диагностика токенов перед запуском (не входит в pytest-тесты):

```bash
python test_bot.py
```

## Тестирование

```bash
pytest
```

Тесты (юнит + интеграционные) не обращаются к реальным VK API, ProxyAPI или сайту ГАРАНТ — только к моками локальным фикстурам (`tests/fixtures/`).

## Архитектура

Проект построен как **ядро + тонкие интерфейсы**: вся бизнес-логика не знает, что такое VK или консоль, а работает с абстрактными `IncomingMessage` / `OutgoingMessage`.

```
core/                          — ЯДРО, вся бизнес-логика, не зависит от транспорта
  models.py                    — IncomingMessage, OutgoingMessage, DialogueEntry, NewsItem, NewsQuery
  ai_client.py                 — AIClient: обёртка над ProxyAPI, с логированием и разбором ошибок
  history.py                   — DialogueHistory (интерфейс) + InMemoryDialogueHistory (лимит по числу сообщений)
  dialogue_service.py          — DialogueService: история + AIClient
  intent_router.py             — IntentRouter: keyword-matching (по основам слов + период) → пресет новостей или обычный диалог
  news/
    query.py, presets.py       — NewsQuery + готовые пресеты (охрана / налоги-бухучёт / всё сразу)
    parser.py                  — NewsParser (интерфейс) + GarantPrimeParser (Playwright, см. ниже)
    formatter.py                — NewsFormatter — список NewsItem → текст для мессенджера
  bot_core.py                  — BotCore.handle_message(IncomingMessage) -> OutgoingMessage — единая точка входа в логику

interfaces/                    — тонкие адаптеры транспорта, без бизнес-логики
  base.py                      — BaseInterface (общий контракт)
  vk/vk_interface.py           — оборачивает vkbottle + приветствие через users.get + постоянная клавиатура-подсказка для новостей
  console/console_interface.py — REPL в терминале (то же ядро, что и VK)
  _future/README.md            — как добавить новый интерфейс (Telegram и т.п.)

tests/                         — pytest: unit/ (по каждому классу ядра) + integration/ (полный путь через BotCore)
main.py                        — единая точка входа: `--vk` / `--console`, сборка зависимостей ядра
test_bot.py                    — ручная диагностика VK_TOKEN/PROXYAPI_KEY (не pytest)
docs/                          — справочная документация vkbottle
tz/                            — технические задания проекта
```

### Модуль новостей ГАРАНТ ПРАЙМ — выбор решения

Страница `https://demo.garant.ru/#/startpage:1` — SPA (контент рендерится JavaScript'ом в браузере), обычный HTTP-запрос отдаёт пустой каркас без данных. Для получения новостей есть два варианта: официальный API ГАРАНТ («Новости ПРАЙМ» / «Тематики ПРАЙМ», требует договора/ключа) или headless-браузер с авторизацией.

**На данный момент выбран вариант Б: Playwright + вход по логину/паролю** (`GARANT_LOGIN`/`GARANT_PASSWORD` в `.env`), т.к. официального доступа к API нет. Реализация — `core/news/parser.py` (`GarantPrimeParser`), докстрока класса фиксирует то же решение и обоснование. `NewsParser` оформлен как интерфейс — при появлении доступа к официальному API можно добавить альтернативную реализацию, не меняя остальной код (`DialogueService`, `BotCore`, интерфейсы).

**Статус: подтверждено end-to-end через реальный VK-бот** (06.09.2026) — реальный пользователь написал боту «изменения в законодательстве за месяц» и получил настоящий отформатированный список новостей ГАРАНТ ПРАЙМ (10 из 20 найденных документов, с заголовками, описаниями, датами и ссылками). По пути к этому результату обнаружены и решены четыре нетривиальных момента:

1. Поля логина/пароля на `account.garant.ru` — React-контролируемые, `page.fill()`/`page.type()` не сохраняют значение, поэтому используется посимвольный ввод через `page.keyboard.press()`.
2. Обычный headless-браузер Playwright почти всегда получал редирект на страницу «уже используется» — оказалось, что это **обнаружение автоматизации** (`navigator.webdriver === true`, `HeadlessChrome` в User-Agent). Подтверждено сравнением с обычным браузером пользователя (там всё работало сразу). Решается библиотекой `playwright-stealth`, которая маскирует признаки автоматизации, плюс имитация человеческого поведения — случайные паузы 1-5с и движение мыши перед кликами (`_simulate_human_pause`).
3. Сайт также буквально просит не логиниться слишком часто одним и тем же аккаунтом («Ваш логин и пароль уже используются. Попробуйте войти через несколько минут.») — штатный анти-abuse кулдаун. `GarantPrimeParser` учитывает это сам: внутренний кулдаун между попытками входа (`MIN_SECONDS_BETWEEN_LOGINS = 60`) и блокировка от одновременных вызовов.
4. **Финальная и решающая находка**: `page.wait_for_load_state("networkidle")` ненадёжен на demo.garant.ru — на странице постоянно открыт WebSocket виджета поддержки (`wss://chat.garant.ru/...`), из-за которого страница может никогда не становиться по-настоящему "сетево-простаивающей". Заменено на точечные `wait_for_selector` для конкретных элементов (поле логина, вкладка «Новости ПРАЙМ», карточки новостей) — именно это дало стабильный результат.

Реальная разметка ленты «Общая лента ПРАЙМ» (`.primeDate` + `.primeDocument`/`.documentTitle`/`.annotationText`) зафиксирована в `_parse_html` и покрыта тестами на офлайн-фикстуре (`tests/fixtures/garant_prime_sample.html`), составленной по образцу настоящей страницы — без обращения к сайту при запуске тестов. Что ещё не сделано: применение самих фильтров `NewsQuery` (дата/тема/орган) через UI вкладки — сейчас `fetch()` читает ленту по умолчанию (обычно последние ~3 месяца), без выставления фильтров сайта под конкретный запрос; см. `TODO` в `core/news/parser.py`, включая перспективный маршрут `/#/fresh/DD.MM.YYYY;DD.MM.YYYY` для фильтрации по периоду напрямую через URL.

## Технологии

- Python 3.12+
- vkbottle — фреймворк для VK ботов
- aiohttp — асинхронные HTTP-запросы к ProxyAPI
- playwright + playwright-stealth + beautifulsoup4 — рендеринг, маскировка автоматизации и парсинг SPA demo.garant.ru
- pytest, pytest-asyncio — тесты
- python-dotenv — загрузка переменных окружения
- certifi — SSL-сертификаты

## Известные ограничения

- История диалога хранится в памяти процесса (`InMemoryDialogueHistory`) — без персистентности, теряется при перезапуске. Ограничена по количеству последних сообщений (не по токенам). Структура (`DialogueHistory`) уже позволяет добавить персистентную реализацию позже без изменений в остальном коде.
- Распознавание новостных запросов — keyword-matching по основам слов (`IntentRouter`), без NLP/ML — осознанное решение для MVP. Кнопки VK-клавиатуры используют ту же логику (шлют текст, который распознаётся как обычное сообщение) — отдельного механизма callback-кнопок не реализовано.
- `GarantPrimeParser`: вход, переход на вкладку «Новости ПРАЙМ» и разбор списка новостей подтверждены end-to-end через реальный VK-бот (см. выше). Не реализовано применение фильтров `NewsQuery` (дата/тема/орган) через UI сайта — `fetch()` пока возвращает ленту без фильтрации по этим полям (см. `TODO` в `core/news/parser.py`). Встроен кулдаун между входами (60с) в рамках одного процесса — если новостные запросы приходят чаще, повторные молча пропускаются с «изменений не найдено». Кулдаун не защищает от коллизий с ДРУГИМИ процессами/скриптами, логинящимися на тот же demo-аккаунт одновременно (актуально только при параллельной отладке, не при обычной работе одного бота).
- Кнопка «Свой период» и явные даты в тексте (`ДД.ММ.ГГГГ-ДД.ММ.ГГГГ`) задают точный период запроса, но реального выбора даты через календарь в VK нет — обычная клавиатура VK не поддерживает такой виджет (потребовался бы отдельный VK Mini App).
- Новый интерфейс (например, Telegram) — только архитектурная точка расширения (`interfaces/_future/`), сама реализация не входит в эту итерацию.
