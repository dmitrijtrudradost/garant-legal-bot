# Гарант — AI-бот для юридического отдела

Чат-бот ВКонтакте (и локальная консоль) с AI на базе GPT-4o Mini через ProxyAPI, плюс модуль новостей ГАРАНТ ПРАЙМ.

## Проблема

Юридическому отделу необходимо оперативно отслеживать изменения законодательства по сфере деятельности организации — например, в области охранной деятельности — и на их основе готовить рекомендации руководству. При этом важно иметь удобный доступ к новостям со смартфона, без привязки к рабочему месту и компьютеру, с возможностью сразу обсудить возникающие вопросы в диалоге.

## Решение

Бот ВКонтакте позволяет со смартфона получать новости ГАРАНТ ПРАЙМ по выбранной сфере деятельности и за нужный период, а также скачивать доступные шаблоны договоров. В том же чате можно задавать вопросы AI-боту и обсуждать рекомендации для руководства с учётом истории диалога. Дополнительно доступен интерфейс локальной консоли.

## Возможности

- Приветствует нового пользователя по имени
- Отвечает на сообщения с помощью GPT-4o Mini, с историей диалога (контекстные ответы)
- Распознаёт новостные запросы («что нового по охране», «изменения в законодательстве», «новости в сфере образование», «из сферы строительство» и т.п.) и присылает подборку новостей ГАРАНТ ПРАЙМ. Приоритет темы: охрана → названная сфера интересов → главные новости по основным сферам. Период от сегодня: «за неделю» / «за месяц» / «за 6 месяцев» / «полгода» / «за год»; свой период — датами `ДД.ММ.ГГГГ-ДД.ММ.ГГГГ` в том же сообщении. Если жёсткий фильтр не сработал, но в тексте есть юридическая лексика («нормативка», «постановление», «ГАРАНТ»…), фразу один раз уточняет AI-классификатор (отдельный вызов, не через историю диалога) и только потом идёт в новости — обычный чат без таких слов по-прежнему не вызывает классификатор
- Если новостей больше десяти, бот показывает страницу и предлагает написать «ещё» (в VK — кнопка «➡️ Показать ещё»); повторного запроса к ГАРАНТ нет, листается сохранённый список
- В VK-версии под каждым сообщением бота — постоянная клавиатура для новостей ГАРАНТ (по одной кнопке на строку, чтобы текст не обрезался на смартфоне): «🛡 Охрана — месяц», «📋 Главные новости — месяц», «➡️ Показать ещё», «Справка». Справка — инструкция, четыре примера запросов и PDF со сферами и фильтрами вложением документа. Кнопка — это просто предзаполненный текст, обычный ввод продолжает работать точно так же
- **Важно про VK-клавиатуры**: они появляются только если в настройках сообщества включены «Возможности ботов» (Управление сообществом → Сообщения → Возможности ботов). Без этой настройки VK отклоняет отправку клавиатуры — бот автоматически подстраховывается и присылает тот же текст без кнопок, а не молчит
- Один и тот же функционал доступен и через VK, и через локальную консоль — оба интерфейса работают поверх общего ядра

## Установка

Полная пошаговая инструкция (локально и на удалённом сервере, включая запуск как systemd-сервиса) — в [INSTALL.md](INSTALL.md). Коротко:

```bash
git clone https://github.com/dmitrijtrudradost/garant-legal-bot.git
cd garant-legal-bot

# Создание виртуального окружения
python -m venv .venv

# Активация
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Windows (CMD):
.venv\Scripts\activate.bat

# Установка зависимостей
pip install -r requirements.txt

# Браузер для модуля новостей ГАРАНТ ПРАЙМ (см. раздел "Модуль новостей" ниже)
playwright install chromium
```

## Настройка

1. Создайте сообщество ВКонтакте: https://vk.com/editapp?act=create
2. Включите в настройках сообщества обработчик сообщений (LongPoll API)
3. Получите токен сообщества. Чтобы прикрепить каталог сфер к справке, у токена должно быть право **документы** (`docs`) — без него инструкция в чат уйдёт, а PDF не прикрепится
4. Зарегистрируйтесь на https://proxyapi.ru и получите API-ключ
5. (Опционально, для новостей ГАРАНТ) — один из двух вариантов доступа: логин и пароль для входа на demo.garant.ru, либо токен официального API ГАРАНТ Коннект (`https://api.garant.ru`)

Создайте файл `.env` в корне проекта:

```
VK_TOKEN=ваш_токен_сообщества
PROXYAPI_KEY=ваш_ключ_proxyapi

# Для модуля новостей ГАРАНТ ПРАЙМ (см. раздел "Модуль новостей" ниже) —
# два независимых режима, можно задать один или оба.
GARANT_LOGIN=
GARANT_PASSWORD=
GARANT_TOKEN=

# Необязательно: явный выбор режима (browser/api/mcp). Если не задано —
# режим определяется автоматически по тому, какие переменные заполнены
# (см. раздел "Модуль новостей" ниже).
GARANT_MODE=

# Режим browser: лента. По умолчанию https://internet.garant.ru
# GARANT_BROWSER_BASE_URL=https://internet.garant.ru
```

Без `GARANT_LOGIN`/`GARANT_PASSWORD`, `GARANT_TOKEN` и `GARANT_MODE` бот продолжает работать как обычно — на новостной запрос он ответит «изменений не найдено» (источник недоступен без учётных данных), при этом весь остальной функционал (диалог, приветствие) не затрагивается.

```bash

```

Тесты (юнит + интеграционные) не обращаются к реальным VK API, ProxyAPI или сайту ГАРАНТ — только к мокам (имитациям внешних сервисов с заданными ответами) и локальным фикстурам — заранее подготовленным тестовым данным (`tests/fixtures/`).

## Выгрузка диалога VK

Сохранить переписку пользователя с ботом для обратной связи или разбора багов. Это живой вызов VK API, не pytest.

Нужен только `VK_TOKEN` сообщества в `.env` (уже используется ботом). Отдельный user-токен и VK Mini Apps не требуются. `peer_id` по умолчанию берётся сам — самый свежий диалог с сообществом.

```bash
python -m exports.export_vk_history
python -m exports.export_vk_history --from 2026-09-10
python -m exports.export_vk_history --from "2026-09-10 15:00" --to "2026-09-10 16:30"
python -m exports.export_vk_history --peer-id 123456789 --from 2026-09-08
```

Файл: `downloads/dialogs/{peer_id}_{ГГГГ-ММ-ДД}_{ЧЧ-ММ-СС}.md`. Время — момент выгрузки. Каталог `downloads/` в `.gitignore`, в git дамп не попадёт.

- `--peer-id` — числовой ID пользователя из адреса `vk.com/id…` (для лички с ботом это ID человека, не `-id` сообщества). Без флага — последний диалог.
- `--from` / `--to` — локальное время компьютера, формат `ГГГГ-ММ-ДД` или `ГГГГ-ММ-ДД ЧЧ:ММ`. Без флагов выгружается вся доступная история выбранного диалога.

## Шаблоны договоров

В режиме `api` бот и отдельная команда скачивают шаблоны из документа ГАРАНТ topic `5703683`. API отдаёт RTF (`GET /v2/topic/{id}/download`); в `.docx` его переводит LibreOffice.

Установка LibreOffice: Windows — [libreoffice.org](https://www.libreoffice.org/download/download-libreoffice/), затем при необходимости `LIBREOFFICE_PATH` на `soffice.exe` (часто `C:\Program Files\LibreOffice\program\soffice.exe`). Ubuntu: `sudo apt install libreoffice`. Если программы нет, файл остаётся в RTF — Word его открывает.

В чате точные фразы, без кнопки и без AI:

- «шаблоны договоров» — нумерованный список, дальше «ещё»;
- «шаблон 1» или «шаблон» и часть названия — один файл;
- «сохранить» — весь список со ссылками на страницы документов. В VK приходит файл `шаблоны-договоров.json`, на диске он лежит в `downloads/templates/templates.json`.

В VK файл приходит документом. В консоли печатается путь. Повторно тот же шаблон берётся из `downloads/templates`, если `last_modified` не менялся. Платные и недоступные пропускаются. В режиме `browser` и без токена бот пишет, что шаблоны доступны только в режиме `api`.

```bash
python -m exports.export_garant_templates --list
python -m exports.export_garant_templates --limit 2
python -m exports.export_garant_templates --only 10164072 --out downloads/templates
```

Папка по умолчанию — `GARANT_TEMPLATES_DIR` или `downloads/templates` (каталог `downloads/` в `.gitignore`). `/html` и `/download` расходуют квоту экспорта; `GET /v2/topic/{id}` — отдельную квоту информации о документе. 423 останавливает выгрузку.

## Архитектура

Проект построен как **ядро + тонкие интерфейсы**: вся бизнес-логика не знает, что такое VK или консоль, а работает с абстрактными `IncomingMessage` / `OutgoingMessage`.

```
core/                          — ЯДРО, вся бизнес-логика, не зависит от транспорта
  garant/api_client.py         — HTTP-клиент api.garant.ru (JSON и RTF), общий для новостей и шаблонов
  models.py                    — IncomingMessage, OutgoingMessage (catalog_html / catalog_pdf / attachment), DialogueEntry, NewsItem, NewsQuery
  ai_client.py                 — AIClient: обёртка над ProxyAPI, с логированием и разбором ошибок
  history.py                   — DialogueHistory (интерфейс) + InMemoryDialogueHistory (лимит по числу сообщений)
  dialogue_service.py          — DialogueService: история + AIClient
  intent_router.py             — IntentRouter: жёсткий keyword-matching + мягкий AI-шлюз для нечётких фраз
  news/
    query.py, presets.py       — NewsQuery + готовые пресеты (охрана / налоги-бухучёт / всё сразу)
    category_tree.py            — резолюция дерева категорий ГАРАНТ (GET /v2/prime) в ID: AND по стемам фразы, префикс-матч
    parser_base.py              — NewsParser (интерфейс, контракт fetch(query) -> list[NewsItem])
    parser_browser.py           — GarantPrimeParser — режим "браузер" (Playwright, см. ниже)
    parser_api.py                — GarantApiParser — режим "api" (официальный REST API, см. ниже)
    parser_mcp.py                — GarantMcpParser — заглушка режима "mcp" (не реализован, см. ниже)
    parser_factory.py            — get_news_parser() — выбор режима по GARANT_MODE/переменным .env
    catalog_html.py             — HTML/PDF-каталог сфер и фильтров (`docs/garant-sfery-i-filtry.*`)
    formatter.py                — NewsFormatter — список NewsItem → текст для мессенджера (общий для всех режимов)
    results_cache.py            — кэш полного списка новостей по peer_id для пагинации «ещё»
  bot_core.py                  — BotCore.handle_message(IncomingMessage) -> OutgoingMessage — единая точка входа в логику

interfaces/                    — тонкие адаптеры транспорта, без бизнес-логики
  base.py                      — BaseInterface (общий контракт)
  vk/vk_interface.py           — оборачивает vkbottle + приветствие через users.get + клавиатура + загрузка PDF-каталога в документы VK
  console/console_interface.py — REPL в терминале (то же ядро, что и VK; каталог — file:// на HTML и PDF)
  _future/README.md            — как добавить новый интерфейс (Telegram и т.п.)

tests/                         — pytest: unit/ (по каждому классу ядра) + integration/ (полный путь через BotCore)
main.py                        — единая точка входа: `--vk` / `--console`, сборка зависимостей ядра
exports/                       — выгрузки вне pytest
  export_vk_history.py         — диалог VK в downloads/dialogs/ (`python -m exports.export_vk_history`)
  export_garant_templates.py   — шаблоны договоров в downloads/templates/
  garant_templates/            — каталог, экспорт, RTF→DOCX
docs/                          — справочная документация vkbottle + каталог сфер/фильтров (`garant-sfery-i-filtry.html`, `.pdf`)
tz/                            — технические задания проекта
```

### Модуль новостей ГАРАНТ ПРАЙМ

Бот получает новости двумя способами:

| Режим | Как работает | Что требуется |
|---|---|---|
| `api` | Через официальный API ГАРАНТ Коннект | Токен `GARANT_TOKEN` |
| `browser` | Через сайт ГАРАНТ с помощью Playwright | `GARANT_LOGIN`, `GARANT_PASSWORD` и установленный Chromium |

Режим можно задать через `GARANT_MODE`. Если он не указан, бот выбирает API при наличии токена, затем браузерный режим при наличии логина и пароля. Без настроек доступа новостной модуль отключён. При ошибке настройки явно выбранного режима автоматического переключения на другой режим нет.

Новости можно выбирать по сфере деятельности и периоду. При выборе темы фильтры территории и вида информации не применяются. Подборки выдаются по десять новостей; команда «ещё» показывает следующую страницу. В «Справке» доступны примеры запросов и каталог сфер.

Режим `mcp` пока не реализован. Ограничения дат и внешних подключений описаны в разделе [«Известные ограничения»](#известные-ограничения).

Устройство модуля, подробные правила фильтрации и обработки периодов, а также сведения о прежних проверках — в [техническом описании](docs/garant-prime-module.md).

## Технологии

- Python 3.12+
- vkbottle — фреймворк для VK ботов
- aiohttp — асинхронные HTTP-запросы к ProxyAPI
- playwright + playwright-stealth + beautifulsoup4 — рендеринг SPA ГАРАНТ (internet.garant.ru) и печать HTML-каталога сфер в PDF для VK
- pytest, pytest-asyncio — тесты
- python-dotenv — загрузка переменных окружения
- certifi — SSL-сертификаты

## Известные ограничения

- История диалога и подборки новостей хранятся в памяти и сбрасываются после перезапуска.
- Распознавание тем и регионов ограничено реализованными правилами и справочниками. Если выбрана тема, фильтры территории и вида информации не применяются.
- В режиме API точная дата каждой новости по умолчанию не запрашивается; используется дата окончания выбранного периода.
- Браузерный режим зависит от доступности сайта ГАРАНТ и его интерфейса. При ограничениях входа может потребоваться повторить запрос позже.
- Для отправки PDF-каталога во ВКонтакте требуется право доступа к документам; для формирования нового PDF — установленный Chromium.
- Поиск по органу власти, виду документа и ключевым словам, режим MCP и интерфейс Telegram не реализованы.

Подробности реализации и прежних проверок — в [техническом документе](docs/known-limitations.md).

## Результат

В одном чате ВКонтакте объединены подборки отраслевых новостей законодательства, доступные шаблоны договоров и диалог с AI. Сотрудник может обращаться к этим возможностям со смартфона, без привязки к рабочему компьютеру, и использовать полученную информацию при подготовке рекомендаций руководству.
